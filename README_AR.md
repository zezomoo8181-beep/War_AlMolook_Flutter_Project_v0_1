# حرب الملوك — مشروع Flutter

نسخة أولية قابلة للتشغيل محليًا والتطوير لاحقًا إلى لعبة متعددة اللاعبين. الواجهة عربية RTL، والرسومات الحالية مرسومة داخل Flutter لتقليل التحميل والاعتماد على ملفات خارجية.

## الموجود حاليًا
- صفحة القرية وخريطة مرسومة محليًا.
- موارد خشب وحجر وحديد وطعام وذهب.
- إنتاج موارد أثناء اللعب، مع احتساب وقت الغياب عند فتح اللعبة مجددًا.
- تطوير المقر والمنشرة والمحجر والمزرعة والثكنات.
- تدريب جنود مع مؤقت.
- مهام توضيحية، إعدادات وإعادة ضبط.
- حفظ محلي باستخدام `shared_preferences`.
- أيقونة Android مخصصة واسم التطبيق «حرب الملوك».

## المتطلبات
- Flutter SDK حديث (يفضل Flutter 3.35 أو أحدث).
- Android SDK وJava 17.
- اتصال إنترنت أول مرة لتنزيل حزم Flutter وGradle.

## التشغيل وبناء APK
افتح الطرفية داخل مجلد المشروع الذي يحتوي على `pubspec.yaml` ثم نفّذ:

```bash
flutter doctor
flutter pub get
flutter analyze
flutter test
flutter build apk --release
```

سيكون ملف التثبيت عادةً هنا:

`build/app/outputs/flutter-apk/app-release.apk`

على Windows يمكنك تشغيل `build_apk_windows.bat` بعد تثبيت Flutter وAndroid SDK؛ السكربت ينفذ الفحص والتنزيل والاختبارات ثم بناء APK.

للتجربة على جهاز موصول عبر USB بعد تفعيل تصحيح USB:

```bash
flutter install
```

> ملاحظة: ملف `android/local.properties` خاص بمسار Android/Flutter SDK على جهاز البناء، لذلك لا يتم تضمين مسارات جهاز محدد في المشروع. أدوات Flutter تملأه عند تجهيز المشروع.

## هيكل مهم
- `lib/main.dart`: الواجهات ومنطق اللعبة المحلي.
- `lib/theme.dart`: الألوان والثيم.
- `android/`: مشروع Android وأيقونة التطبيق واسم الحزمة `com.waralmolook.game`.
- `assets/app_icon.svg`: المصدر المتجهي لفكرة الأيقونة.

## حدود النسخة الحالية
هذه ليست لعبة أونلاين بعد: الموارد والحفظ محليان على الجهاز، والخريطة لا تعرض لاعبين حقيقيين. الأونلاين يحتاج API وخادمًا موثوقًا وقاعدة بيانات وتسجيل دخول ومعالجة المعارك على الخادم. لا تستخدم هذه النسخة لإجراء مدفوعات أو حفظ بيانات حساسة.
